# Benchmarking

Benchmarking is a first-class scientific and release-engineering subsystem.

Suites cover hallucination, latency, throughput, robustness, bias, adversarial testing, and reproducibility. Every benchmark should define input data, metric, threshold, baseline, and artifact format.

The committed operational benchmark bundle in `benchmarking/results/2026-05-20` is generated by `benchmarking/reproducibility/run_operational_benchmark.py` and includes JSON, CSV, Markdown, and comparison outputs.
