# Diagrams

Architecture diagrams are stored as Mermaid files so they can be reviewed as text and rendered by GitHub or documentation tooling.

- `service_topology.mmd`: deployed SaaS topology.
- `request_lifecycle.mmd`: end-to-end API/evaluation path.
- `rag_flow.mmd`: retrieval-augmented alignment flow.
- `inference_routing.mmd`: GPU-aware router decision path.
- `safety_pipeline.mmd`: prompt and response safety gates.
- `agent_orchestration.mmd`: future agent workflow state model.
