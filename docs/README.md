# Documentation

Documentation is split by operational audience:

- `api/`: OpenAPI contracts and endpoint behavior.
- `deployment/`: environment setup, release, and rollback notes.
- `benchmarks/`: benchmark methodology and report interpretation.
- `diagrams/`: Mermaid diagrams for architecture and workflows.
- `tutorials/`: practical developer and researcher guides.
- `papers/`: paper notes and citation tracking.
- `datasets/`: dataset schema, registry, and governance notes.
