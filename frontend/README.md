# Frontend

Frontend surfaces make research and operations understandable:

- `web/nextjs_app`: starter product shell.
- `web/dashboard`: experiment and deployment status.
- `web/admin_panel`: model, dataset, and deployment administration.
- `web/experiment_visualizer`: run comparison and ablation analysis.
- `web/benchmark_viewer`: benchmark reports and regressions.
- `web/analytics`: usage, cost, latency, and safety analytics.
- `mobile`: future mobile companion shell.

The Next.js app now includes a public landing page plus internal routes for `/dashboard`, `/benchmarks`, `/deployment`, and `/traces`.
