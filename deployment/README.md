# Deployment

Deployment assets make the platform runnable in local, staging, and production-like environments.

This tree includes Docker, Kubernetes, Helm, Terraform, nginx, Cloudflare, GPU cluster, and autoscaling scaffolds.

Deployment paths are also prepared for Vercel frontend hosting, Render/Railway API hosting, AWS, and Google Cloud. Live deployment requires provider accounts, secrets, database, Redis, and inference credentials.
